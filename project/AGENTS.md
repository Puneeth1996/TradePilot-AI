# AGENTS.md

## Purpose
This repository is maintained by both humans and AI coding agents.

## Required Startup Procedure
Before making changes, read:

1. docs/ARCHITECTURE.md
2. project/PROJECT_MEMORY.md
3. project/CURRENT_STATE.md
4. project/NEXT_STEPS.md
5. project/DECISIONS.md

## Required Shutdown Procedure
Before ending work:

- Update WORK_LOG.md
- Update CURRENT_STATE.md
- Update NEXT_STEPS.md
- Update AGENT_HANDOFF.md
